# Weekly desktop UI polish

Goal: compact Windows productivity UI, preserving current Task/recurrence/history semantics and all Electron layers.

## Design

Concept: C:/Users/EricWu/.codex/generated_images/01a14d64-ca95-70c3-8b5b-53cdd854dcdf/exec-dd1eb6c1-3842-4846-a7fb-c62dffdea4bc.png (preview only, not a runtime asset).

- Neutral #f5f6f8 workspace, white surfaces, #2563eb accent, dark slate text, muted #64748b, light #dfe4eb borders. Segoe UI/system fonts, 13px base, 20px application heading, 22px section heading, 14px card titles. Controls 34–36px, radii 6–8px, 24px outer gutters. No gradients or animation.
- Separate white app header, week toolbar, seven-day bordered board. Centered weekday/date headers; today's blue date circle/pale column. Compact cards show a square toggle, clickable title, time and recurrence only; completed cards stay readable but quieter.
- Shared native dialog primitive supplies modal focus containment, Escape/cancel, backdrop and focus restoration. Add/Edit use the same TaskForm in a centered 520px dialog. Native dialogs fit narrow windows and scroll internally.
- Task title opens a separate details dialog aligned to the right. Summary and Edit Task action appear before collapsed history; history metadata stays secondary. Edit temporarily replaces the detail dialog to avoid stacked modal traps. Manage tasks remains a quiet secondary entry for off-week tasks.
- Refine intentional empty/loading/error states and history editor spacing without changing APIs/model. Horizontal board scrolling below desktop widths.

## Review and visual fidelity ledger

- Header: calendar outline mark, left app title, right blue Add Task action match the concept. Segoe UI is deliberately compact (20px heading/13px base) for a desktop window rather than scaling up with screenshot dimensions.
- Toolbar: week caption/date on the left, previous/this-week/next group and filter on the right. At narrow widths the controls wrap; the seven-day board alone scrolls horizontally.
- Board: white shared container, seven equal columns, soft vertical dividers, pale blue today column and filled blue date circle. Localized weekday/time/date formatting is retained. A localized day suffix initially overflowed the circle; numeric day-only rendering fixes it.
- Cards: 18px square toggle and text column with clickable title/time/recurrence; muted completed styling, restrained borders/shadows. Imported metadata and separate action rows removed. Current-rule projection/completion APIs unchanged.
- Palette/type: flat #f5f6f8 workspace, white surfaces, #2563eb accent, slate text, 6–8px corners; no gradients/animation/external assets. Small muted text on today uses a darker shade for contrast.
- Copy: top-level concept labels retained (Weekly schedule, Add Task, This week, All tasks, Manage tasks); real user data replaces concept sample tasks. Visible dates/times follow OS locale. Empty/loading/error states add only the requested functional guidance.
- Add/Edit: one shared native modal and TaskForm, keyboard focus containment, Cancel/Escape/backdrop, pending-save guard; detail/history is a separate right-aligned modal. These secondary states use the primary concept's controls and spacing; they do not add navigation/product features.
- Independent review found pending-save dismissal, moved-card focus return and 320px toolbar overflow. Fixed all three; real Electron checks exercise delayed real IPC, focus fallback and 320px width. A first QA run also failed initial form focus; explicit initial-focus targeting now passes.
- Real visual QA screenshots: `C:/Users/EricWu/.codex/visualizations/2026/10/18/01a14d64-ca95-70c3-8b5b-53cdd854dcdf/polish-jZmOSE/` at concept-native 1586x992, 1440x900, 1000x700, 600x700 and 320x700, plus form/details/history states. Tradeoffs: light theme only; compact desktop density; narrow windows preserve readable columns via horizontal scrolling; editing replaces details instead of stacking dialogs. No visual concept PNG is shipped as application UI.
